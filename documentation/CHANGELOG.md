# Changelog
All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.5.0] - 2026-01-Unspecified
### Changed
- `AdswizzAdZone` and `AdswizzShimZone` instance creation to Builder pattern to improve **Java** interoperability. For more details, please visit the updated [AdInsertion](JvmSDK/SDK/AdInsertion.md) page.

## [0.4.0] - 2025-12-19
### Added
- This is a Beta version, some APIs may change in future releases based on feedback. 
- Brand new AddswizzSDK for JVM applications written in **Kotlin**
- Support for **Java**
