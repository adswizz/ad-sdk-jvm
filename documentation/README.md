# AdswizzSDK for JVM projects

This documentation will guide you on how to integrate and use the AdswizzSDK for JVM projects in order to monetize your application.
Learn the basics of how to request ads from the Adswizz Server and how to generally use the public APIs for specific scenarios in order to fit your application needs.
